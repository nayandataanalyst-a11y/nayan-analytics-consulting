# Nayan React Portfolio

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally http://localhost:5173.

## Build

```bash
npm run build
```

## Customise

- Edit profile content in `src/data.js`.
- Update social URLs in `src/components/Hero.jsx`.
- Replace `nayan@example.com` in `src/components/Contact.jsx`.
- Add `Nayan-Dholakia-Resume.pdf` to the `public` folder.
